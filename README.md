# Ocrevus Social Intelligence

An AI-powered social listening and classification platform for analysing conversations around Ocrevus and Multiple Sclerosis (MS).

## Features
- Text preprocessing and noise filtering
- Drug and entity detection
- LLM-based classification
- Sentiment and topic analysis
- Structured insights and reporting

## Tech Stack
Python | Gemini API | LLMs | Data Analytics
